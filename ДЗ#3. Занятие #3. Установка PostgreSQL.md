#### Настройки Ubuntu

Проверим IP адрес, чтобы подключатсья через SSH:

```bash
ip addr
```

Проверим доступные локали:

```bash
locale -a
```

```bash
C
C.utf8
POSIX
ru_RU.utf8
```

Отсутствует локаль `en_US.UTF-8`.  
Добавим:

```bash
sudo locale-gen en_US.UTF-8
Generating locales (this might take a while)...
  en_US.UTF-8... done
Generation complete.
```

Обновляем ОС и компоненты:

```bash
sudo apt update
sudo apt upgrade
```

### Docker

1. Идём на страницу официальной документации [Install Docker Desktop on Ubuntu](https://docs.docker.com/desktop/install/linux/ubuntu/), 
2. читаем `The latest Ubuntu 24.04 LTS is not yet supported`,
3. расстраиваемся, скачиваем образ [Ubuntu 22.04.5 LTS (Jammy Jellyfish)](https://releases.ubuntu.com/22.04/),
4. переустанавливаем Ubuntu [как мы уже это делали](#ubuntu).
5. Перечитываем презентацию к уроку, находим правильную ссылку на [Docker Engine](https://docs.docker.com/engine/install/ubuntu/).
6. Видим, что в разделе `OS requirements` указана версия `Ubuntu Noble 24.04 (LTS)`
7. переустанавливаем Ubuntu [как мы уже это делали](#ubuntu) с имиджа `Ubuntu Noble 24.04 (LTS)`.
8. Используем метод установки из `apt` репозитория [по инструкции](https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository).  

В процессе установки получаем сообщение

```bash
curl: (28) Failed to connect to download.docker.com port 443 after 300382 ms: Timeout was reached
```

Вспоминаем, что выход в интернет через прокси, и прокси, настроенный при установке, используется только `apt`.  
Настраиваем прокси для `curl` и повторяем попытку настройки apt репозиториев.

```bash
nano ~/.curlrc
```

при этом, если вызвать `curl` с повышением привилегий, используя `sudo`, настройки прокси игнорируются. Поэтому ключ качаем вручную, и вручную его кладём к ключам репозиториев:

```bash
curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o docker.asc
sudo mv docker.asc /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc
```

После этого пакеты из репозитория Docker становится доступен для инсталляции, чем мы и воспользуемся:

```bash
sudo apt-get install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
```

9. Проверяем
```bash
sudo service docker start
sudo docker run hello-world
[sudo] password for pg:
Unable to find image 'hello-world:latest' locally
docker: Error response from daemon: Get "https://registry-1.docker.io/v2/": net/http: request canceled while waiting for connection (Client.Timeout exceeded while awaiting headers).
See 'docker run --help'.
```

Снова вспоминаем, что работаем через прокси, но не сдаёмся, не прописываем прокси для всей системы, делаем точечено - так интересней.  
Добавдяем Docker настройки прокси по инструкциям:
* [Daemon proxy configuration](https://docs.docker.com/engine/daemon/proxy/),
* [ Configure Docker CLI to use a proxy server](https://docs.docker.com/engine/cli/proxy/).

CLI:

```bash
mkdir ~/.docker
nano ~/.docker/config.json
```

Daemon:

```bash
 sudo mkdir -p /etc/systemd/system/docker.service.d

```
